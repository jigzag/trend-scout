# サイト立ち上げ手順（WordPress ＋ エックスサーバー）

所要時間：40分〜1時間。費用：月1,000円前後（12か月以上の契約なら独自ドメインは無料）。

## 決めたこと（2026-10-04）
| 項目 | 選んだもの | 理由 |
|---|---|---|
| 掲載先 | 独自ドメインの WordPress | アフィリエイトに制限がない。REST API で下書きを自動投稿できる（Ver.2）。記事が自分の資産になる |
| サーバー | エックスサーバー（スタンダード） | 国内で利用者が多く、困ったときに情報が見つかりやすい。申し込みと同時に WordPress まで入る |
| テーマ | Cocoon（無料） | 費用をかけずに始められる。アフィリエイト向けの機能（広告表示、目次、吹き出し）がそろっている。有料テーマは収益が出てから検討する |

---

## 0. 先に決めておくもの
- **サイト名**（後から変更できる）
- **ドメイン名**：`nocode-ai.net` に決定（後から変更できない）
  - 短く、読みやすく、ジャンルが分かるもの。ハイフンは1つまで
  - `.jp` はスタンダードプランの無料特典の対象外（無料はプレミアム以上）なので `.net` にした
  - `nocode-ai.com` と `nocodeai.jp` は取得済みだった。`nocode-ai.net` は 2026-10-04 時点で空いていた
- **WordPress のユーザー名とパスワード**（パスワードマネージャーなどに控える）

## 1. エックスサーバーに申し込む

> 注意：「WordPressクイックスタート」を使うと、**10日間の無料お試しはなく、申し込みと同時に支払い**が発生します。
> そのかわり、ドメイン取得・SSL・WordPress のインストールが一度に終わります。手間が少ないので、こちらで進めます。

1. [エックスサーバー](https://www.xserver.ne.jp/) を開き、「お申し込み」をクリック
2. 「10日間無料お試し 新規お申込み」をクリック（クイックスタートを選ぶと、無料お試しではなく本契約になります）
3. プランは「**スタンダード**」を選ぶ
4. 「WordPressクイックスタート」の「**利用する**」にチェックを入れる
5. 契約期間は「**12ヶ月**」以上にする（独自ドメインが永久無料になる条件）
6. ドメイン名に `nocode-ai`、末尾に `.net` を選んで、取得できるか確認する
7. WordPress情報を入力する
   - ブログ名：サイト名
   - ユーザー名・パスワード：手順0で決めたもの
   - テーマ：**Cocoon** を選ぶ（一覧になければ「WordPressデフォルトテーマ」で進め、手順3で入れる）
8. 個人情報と支払い情報を入力して申し込む
9. 届いたメール「【xserver】■重要■サーバーアカウント設定完了のお知らせ」を保存しておく

サイトが表示されるまで、**最大1時間ほど**かかります。「無効なURLです」と出ても、少し待ってください。

## 2. 自動投稿のためのサーバー設定（重要）

GitHub Actions は**海外のサーバー**から動きます。エックスサーバーは、初期状態で海外からの REST API を止めているため、このままでは Ver.2 の自動投稿が `403` で失敗します。

1. [サーバーパネル](https://www.xserver.ne.jp/login_server.php) にログイン
2. 「WordPress」の欄 →「**WordPressセキュリティ設定**」をクリック
3. 対象のドメインの「選択する」をクリック
4. 「**国外アクセス制限設定**」タブを開く
5. 「**REST API アクセス制限**」を「**OFF**」にして「設定する」をクリック
   - ほかの項目（ダッシュボード、XML-RPC など）は **ON のまま**にする

## 3. WordPress の初期設定

`https://nocode-ai.net/wp-admin/` を開き、手順1-7のユーザー名とパスワードでログインします。

1. **テーマ**：「外観」→「テーマ」に「Cocoon Child」があれば有効化する。なければ「新規追加」で Cocoon を検索し、親テーマ（Cocoon）と子テーマ（Cocoon Child）の両方を入れて、**子テーマを有効化**する
   - Cocoon は WordPress 公式のテーマ一覧にない場合があります。そのときは [Cocoon公式サイト](https://wp-cocoon.com/) からダウンロードして「テーマのアップロード」を使います
2. **パーマリンク**：「設定」→「パーマリンク」→「**投稿名**」を選んで「変更を保存」
   - 記事を出した後に変えるとURLが変わるので、**最初に必ず**設定する
3. **一般**：「設定」→「一般」で、サイトのタイトルとキャッチフレーズを入れる
4. **サンプル記事の削除**：「投稿」の「Hello world!」と、「固定ページ」の「サンプルページ」をゴミ箱へ入れる

## 4. 収益化の前に必要なページ

ASP や Amazon アソシエイトの審査では、次のページが見られます。

1. **プライバシーポリシー**：「設定」→「プライバシー」でひな形から作り、公開する
2. **運営者情報**（固定ページ）：運営者名（ハンドルネームでよい）、サイトの目的、お問い合わせ先
3. **お問い合わせ**：プラグイン「Contact Form 7」でフォームを作る
4. **広告の表記**：ステマ規制（2023年10月〜）により、広告リンクのある記事には「**PR**」や「広告を含みます」の表示が必要です
   - 記事ごとの表示は Ver.2 で自動化する（SPEC 参照）。サイト全体の方針は運営者情報にも書いておく

## 5. Ver.2 で使う「アプリケーションパスワード」（Ver.2 の作業時でよい）

普段のログインパスワードとは別に、自動投稿専用のパスワードを発行します。

1. 「ユーザー」→「プロフィール」を開き、一番下の「**アプリケーションパスワード**」へ
2. 「新しいアプリケーションパスワード名」に `trend-scout` と入れて「新しいアプリケーションパスワードを追加」
3. 表示されたパスワード（`xxxx xxxx xxxx ...`）を控える。**この画面を閉じると二度と表示されない**
4. GitHub の Secrets に、次の**3つを別々に**登録する（README の手順と同じ画面）

   | Name | Secret |
   |---|---|
   | `WP_URL` | `https://nocode-ai.net`（最後の `/` は付けない） |
   | `WP_USER` | WordPress のユーザー名 |
   | `WP_APP_PASSWORD` | 手順3のパスワード（スペースを含めたままでよい） |

## 次の工程
- 記事を5〜10本ほど公開する（Ver.1 の記事生成 ＋ 自分で試した画面）
- その後、ASP（A8.net、もしもアフィリエイトなど）と Amazon アソシエイトに申請する
  - Amazon アソシエイトは、申請後180日以内に3件の売上がないと承認されない（条件は変わることがあるので、申請時に公式で確認する）
