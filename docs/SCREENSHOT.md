# スクショの撮り方（Windows サンドボックス）

記事の導入手順に、実際の画面を載せるための手順です。
Windows サンドボックスは、Windows 11 Pro に入っている「使い捨ての Windows」です。閉じると中身が全部消えるので、知らないアプリを入れてもふだんの Windows は汚れません。

## 最初に1回だけ：サンドボックスを有効にする
1. スタートボタンを右クリック →「ファイル名を指定して実行」
2. `optionalfeatures` と入力して「OK」
3. 一覧から「**Windows サンドボックス**」にチェックを入れて「OK」
4. 「今すぐ再起動」

（一覧にない、またはチェックできないときは、BIOS の仮想化がオフの可能性があります。その場合はふだんの PC で試しても構いません）

## 毎回の流れ
1. スタートメニューで「Windows Sandbox」を開く（まっさらな Windows の窓が出ます）
2. サンドボックスの中の Edge で、記事のツールの公式サイトを開いてダウンロード・インストール
3. 進めながら、要所で **Win + Shift + S** で画面を撮る（サンドボックスの窓をクリックしてから押す）
   - 撮った画像はクリップボードに入るので、ふだんの PC の LINE（PC版）にそのまま貼り付けて送れます
   - おすすめの場面：ダウンロードボタン / インストール画面 / 警告が出た画面 / 初回起動の画面 / 最初に使った結果
4. LINE に画像を送る →「スクショを受け取りました」と返ってくる
5. 1分ほど待ってから、候補の番号を送る（気づいたことはメモで。例 `1 警告は詳細情報→実行で進めた。初回DLは30分`）
6. 終わったらサンドボックスの窓を閉じる（中身は消えます）

## 注意
- メールアドレス・名前・パスワードが写っている画像は送らない（記事にそのまま載ります）
- 合わない画像は使われずに残り、7日で消えます。すぐ消したいときは LINE で `スクショ取消`
- 何十GBもあるアプリ（Survival LLM のフル版など）は、サンドボックスでは容量が足りないことがあります。軽量版を選ぶか、途中までの画面で十分です
